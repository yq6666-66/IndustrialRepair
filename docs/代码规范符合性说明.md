## 3. 业务规则与 AI 边界

| 规范 | 实现 |
|---|---|
| 工单状态统一流转 | ✅ 仅经 `WorkOrderService` + 存储过程（usp_CreateOrder/AssignOrder/TakeOrder/CompleteOrder/CancelOrder），触发器留痕 |
| `IImageRecognizer` 隔离课程模型 | ✅ 接口已落地；当前实现 RecognitionEngine V2（ZXing 解码 → OpenCV 视觉 → 特征库融合，OpenCV 异常自动降级）。课程模型交付后实现该接口替换，UI/流程零改动 ⏳ |
| 识别候选与人工确认留痕 | ✅ Top3 候选随工单写入 `Recognized`：≥60% 记「自动识别」，<60% 明确标注「需人工确认」，候选全列保留；识别在界面预览与提交间共享同一份候选（不重复识别） |
| 固定答案不得冒充 AI | ✅ 无固定演示答案；特征库来自配件档案 FeatureJson（颜色/形状/尺寸），理由可解释（主色距离/圆度/占比） |

| 无规则不默认 0 | ✅ 规则为空返回空列表；工单状态不符/重复算料由存储过程拦截并中文报错 |
| 扫码多源同流程 | ✅ `IScannerInput`：SerialScannerInput（硬件）/ SimulatedScannerInput（无硬件演示），手动录入与图片扫码走同一 `LookupPart` 流程；串口回调 `BeginInvoke` 封送 UI 线程 |

## 4. 数据库、安全与错误处理

- ✅ 全部参数化 SQL（SqlParameter），无字符串拼接用户输入
- ✅ 出库扣减 + 流水同事务（usp_IssuePicking，XACT_ABORT，缺口回滚并提示缺料）
- ✅ 零件编码唯一；数量非负约束；停用不物理删除
- ✅ bcrypt（BCrypt.Net-Next，cost 11，随机盐）；另有 SHA256 仅用于校验和类场景，口令存储一律 bcrypt
- ✅ 权限双层：界面导航按权限显隐（FMain）+ 业务操作处再校验（服务/过程内）
- ✅ 连接串默认本机 LocalDB 受信连接，无密钥入仓；全局异常钩子落盘日志不含口令/完整连接串
- 🟡 任务书授课清单中的 JWT / CSRF：纯桌面单机形态不适用（无 HTTP 会话可伪造）；已实现图形验证码、MFA 邮箱二次验证、登录失败锁定、30 分钟会话超时作为替代性安全项
- ⏳ 双因素若课程要求 Web 端形态再补服务端规范
