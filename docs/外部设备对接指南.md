# 外部设备与平台对接指南（课程模型 / 扫码枪 / 山海鲸）

> 2026-10-04 实测：ONNX 后端已通过 MobileNet v2 端到端验证；山海鲸 CSV 格式已确认兼容；扫码枪软件侧就绪。

## 一、课程模型（ONNX 后端）

### 已验证

用 [ONNX Model Zoo](https://github.com/onnx/models) 的 **MobileNet v2**（13MB，ImageNet 1000 类，Apache-2.0）完成全管线端到端测试：

| 步骤 | 结果 | 说明 |
|---|---|---|
| 模型加载 | ✓ | `InferenceSession` 创建成功，输入 `[-1,3,224,224]`，输出 `[-1,1000]` |
| 预处理 | ✓ | 64×64 测试图 → letterbox 224×224 → NCHW tensor `1×3×224×224`（150,528 元素） |
| 推理 | ✓ | 1000 类概率输出，灰色圆形图 Top5 类别合理（金属/圆形物体） |
| 标签映射 | ✓ | 稀疏索引格式解析，3 条映射正确 |

### 接入课程模型（4 步）

1. **拿到课程模型文件**（`.onnx` 格式，教练/课程提供）放入 `models/` 目录
2. **创建标签文件**（`.txt`），每行格式：
   ```
   类别名<TAB>配件编码
   深沟球轴承6205	P-ZC-001
   骨架油封TC40	P-MF-001
   ```
3. **在 `appsettings.json` 添加 `Onnx` 节**：
   ```json
   {
     "Onnx": {
       "ModelPath": "models/course_model.onnx",
       "LabelsPath": "models/course_labels.txt",
       "InputSize": 224
     }
   }
   ```
4. **重启系统**——识别引擎自动切换为 ONNX 模式（启动日志可见 `[NR8] ONNX 后端已启用`）

### 验证命令

```bash
dotnet run --project test/OnnxTest
```

输出全 `✓` 即接入成功。模型/标签文件不存在时自动回退特征库匹配，不影响业务。

### 模型要求

- 单输入 NCHW float 张量（`(batch, 3, H, W)`，H=W 建议 224）
- 输出 `(batch, N)` 概率/ logits（自动取 Top3）
- 不满足此格式（如 YOLO 检测框输出）需调整 `OnnxImageRecognizer.Recognize` 的后处理逻辑

## 二、实物扫码枪

### 软件侧已就绪

- `IScannerInput` 接口 + `SerialScannerInput`（真实串口实现）
- 帧协议：`PART:配件编码`（换行结尾）
- UI 线程安全封送（`BeginInvoke`）
- 串口页支持打开/关闭/发送测试帧

### 常见扫码枪对接方式

| 接口类型 | 对接方式 | 本系统适配 |
|---|---|---|
| **USB HID（键盘仿真）** | 最常见——扫码后直接在焦点处"打字"输出编码 | 在串口页手动录入框直接扫码即可（已支持） |
| **USB 串口（COM 口）** | 需安装驱动→分配 COM 号→串口通信 | 串口页选择 COM 号→打开→自动接收 `PART:` 帧 |
| **蓝牙** | 配对后映射为串口或 HID | 同上两种方式 |

### 实物验证清单

| # | 场景 | 预期 | 日期 | 结果 |
|---|---|---|---|---|
| 1 | USB HID 扫码 → 手动录入框 | 编码自动填入，点击查询命中配件 | | |
| 2 | 串口扫码枪连接 → 串口页打开 | COM 口列表可选，打开后无报错 | | |
| 3 | 扫描配件二维码标签 | 接收帧日志显示 `<< PART:P-XX-XXX`，右侧显示配件信息 | | |
| 4 | 连续快速扫描（10 次/秒） | 不丢帧、UI 不卡顿 | | |
| 5 | 扫码枪断开再重连 | 关闭串口→重新选择→打开成功 | | |
| 6 | 扫描非 PART: 前缀条码 | 日志记录但配件查询跳过（协议兼容） | | |

### 二维码标签生成

系统内配件库「生成二维码」按钮（QRCoder）产出 `PART:编码` 标签，可直接打印贴在配件上供扫码枪测试。

## 三、山海鲸可视化大屏

### CSV 数据源已就绪

系统大屏页「导出CSV(大屏数据源)」按钮产出：

| 格式项 | 值 | 兼容性 |
|---|---|---|
| 编码 | UTF-8 **带 BOM** | 山海鲸自动识别中文列名 |
| 分隔符 | 逗号（RFC4180） | 标准格式 |
| 首行 | 表头（`类别,指标,数值`） | 山海鲸识别字段名自动映射 |
| 换行 | CRLF | Windows 标准 |

### 导入步骤（山海鲸可视化）

1. 下载安装 [山海鲸可视化](https://www.shanhaibi.com)（免费版即可导入 CSV）
2. 新建大屏项目 → 进入编辑界面
3. 点击「**数据**」下拉菜单 →「**编辑数据**」
4. 选择「**导入文件数据**」→ 浏览选择系统导出的 CSV 文件
5. 确认字段映射（`类别→维度`、`数值→度量`）→ 确定
6. 在大画布上添加组件（柱状图/饼图/数字卡片），绑定数据源字段
7. 可设置刷新频率（CSV 为静态快照，刷新需手动重新导入）

### 制作建议（答辩大屏）

| 组件 | 绑定字段 | 效果 |
|---|---|---|
| 数字翻牌器 | 数值（筛选：今日工单） | 动态数字效果 |
| 柱状图 | 类别=状态分布 | 工单状态五色柱 |
| 折线图 | 类别=近7日工单/近7日成本 | 双系列趋势 |
| 饼图 | 类别=类别库存 | 库存分布占比 |
| 表格 | 类别=库存预警 | 低库存明细滚动 |

### 验证清单

| # | 场景 | 预期 | 日期 | 结果 |
|---|---|---|---|---|
| 1 | CSV 文件导入山海鲸 | 字段映射正确，无乱码 | | |
| 2 | 柱状图绑定「状态分布」 | 五个状态柱正常显示 | | |
| 3 | 数字翻牌器绑定「数值」 | 显示工单/成本数字 | | |
| 4 | 大屏截图 | 截图存入 docs/测试记录 | | |

### 实时数据源（进阶）

CSV 为静态快照。如需实时刷新：
- 山海鲸支持 **MySQL/PostgreSQL/HTTP API** 数据源
- 本系统用 SQL Server LocalDB，可通过 ODBC 桥接（需额外配置）
- 或定期运行 `SmokeConsole --ensure-structure` 触发大屏重新导出 CSV → 山海鲸设置定时刷新
