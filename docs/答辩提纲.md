## 一、开场陈述（约 1 分钟）

- 项目：工业维修智能化零件分配平台——"拍照·识别·审阅·算料"一体化智能维修系统。
- 业务闭环：报修拍照 → 识别候选 Top3 留痕 → 工程师**材料审阅（确认重点零件）** → 整机 BOM×冗余智能算料 → 领料出库 → 完工 → 大屏统计。
- 技术栈：C# .NET 8 WinForm + SunnyUI + ADO.NET + SQL Server（21 表/14 存储过程/3 触发器/8 视图/事务/版本化迁移）+ SerialPort + MQTT。
- 界面：深灰电光蓝科技风深色主题（单一主题、25 个语义色 token、文字对比度按 WCAG AA 校核）。
- 质量：单元测试 169/169、端到端冒烟 85/85（独立测试库强制隔离）、SQL 冒烟、数据库升级演练与识别评测工具出真实数字。

> 登录提示：用户名会被记住，切账号只需改用户名 + 密码 123456 + 验证码（点图可刷新，大小写不敏感）。
> 时间不够的裁剪顺序：9 加分项 → 8 日志 → 6 扫码 → 7 IoT 改口头讲；保底 1–4（核心闭环 + 大屏）。

1. **reporter 登录**（报修人张三）→ 工单中心 → 新建报修：**模板选「轴承异响」**（自动预填类型/优先级/描述）→ 设备任选 → **拍照/选择照片 → 选《现场照片_深沟球轴承6205.png》** → 右侧出现"拍照识别 Top3：深沟球轴承6205 100%"（讲：ZXing 二维码直达 100%，无码照片走 OpenCV 特征库给候选、分数是匹配分非概率）→ 提交。
2. **admin 登录** → 工单中心（列表按单号倒序，刚提交的在最上方）→ 选中刚才的工单 → 派单 → 选「工程师-李工」（讲：RBAC——派单按钮仅管理员可见，服务层再校验，越权调用直接被拒）。
3. **engineer 登录** → 工单中心 → 选中工单 → 接单 → **详情：材料审阅**——点「确认：深沟球轴承6205 100%」（讲：BOM 内仅 ★ 标记重点不改数量；BOM 外必须填人工用量+理由，按 CEILING(用量×冗余) 追加）→ 关闭 → 智能算料·领料 → 为工单算料：选工单、冗余 1.10 → 生成领料单（讲：审阅闸门、审阅快照随单固化、历史清单可解释）。
   **注意**：此界面**没有"领料出库"按钮**——工程师无出库权限，这正是 RBAC 职责分离，可主动讲。
4. **admin（或 warehouse 库管员）登录** → 智能算料·领料 → 选中新领料单 → **领料出库**（讲：存储过程事务+行锁，库存不足整体 Rollback 报缺口；一工单同时至多一张未出库单——唯一过滤索引兜底并发）→ 回工单中心 **完工**（填维修总结）。
5. **大屏**（UIBarChart 状态分布 / UILineChart 近 7 日 / 排行 / 库存预警，预警由触发器写入；可"导出CSV"对接山海鲸类大屏）。
6. admin → 配件库「生成二维码」（QRCoder）→ 串口页「从图片扫码」选《二维码_接触器（扫码演示）.png》（或手动录入）（讲：扫码源统一 IScannerInput 接口——串口/模拟器/图片/手动同一流程，PART:编码 协议统一）。
7. admin → IoT·MQTT 遥测：启动网关（MQTTnet 内嵌 Broker 127.0.0.1:18835）→ 实时曲线/健康表 → 越限自动创建 [IoT自动报修] 工单（10 分钟冷却防重复，冒烟有确定性断言）。
8. admin → 用户与日志（登录/操作/审阅留痕全可查）。
9. （加分项，如时间允许）命令行跑 `test/RecognizeEval --mode=qr`：扫码回环 6/6；`--mode=visual` 合成图 Top1 0/3——讲"评测出真数"：识别分数是匹配分不是概率，真实效果待课程模型+真实图集，不吹牛。

## 三、亮点回答准备（高频提问）

1. **密码怎么存的？** bcrypt（cost=11）+ 失败 5 次锁 10 分钟 + 图形验证码 + 可选 MFA（演示流程：验证码界面直显，未接真实 SMTP，如实说明）。
2. **防 SQL 注入？** DAL 与存储过程全部 SqlParameter 参数化，无拼接。
3. **事务在哪里？** ① C# BeginTransaction（注册）；② usp_ReviewMaterials 审阅字段+留痕同事务；③ usp_GeneratePicking（XACT_ABORT+TRY/CATCH，含审阅快照）；④ usp_IssuePicking 出库（不足回滚报缺口）；另有一工单至多一张未出库单的**唯一过滤索引**兜底并发。
4. **触发器做什么？** 工单真实新增/状态变化留痕（普通字段更新不误记）；库存跌破下限预警；领料明细留痕。
5. **识别为什么不用深度学习？** ZXing 二维码直达 + OpenCV 传统视觉×特征库融合：免训练免 GPU、理由可解释、演示稳；贴码即 100% 命中。识别引擎实现 IImageRecognizer 接口，课程模型到位后同接口替换；配套 RecognizeEval 评测工具可对任何实现出 Top1/Top3/混淆矩阵。
6. **人工确认那一步做什么用？** 照片判不准内部损坏——识别只给候选，工程师审阅确认重点零件后才允许算料：BOM 内标 ★、BOM 外按人工用量追加；审阅快照固化到领料单，防止事后改口说不清。
7. **CSRF 在 C/S 怎么落实？** 针对 Web 会话；本系统以会话令牌 + 30 分钟滑动超时 + 操作日志审计等价落实，并在服务层做会话/权限/获派二次校验。
8. **冗余系数？** BOM 用量×冗余（1.00~2.00 可调）向上取整；纯函数 BomCalculator 与存储过程语义一致，冒烟有对拍断言。
9. **怎么部署/升级？** publish 拷贝 + Runtime 8 + LocalDB，"一键初始化"建库播种；结构升级走 schema_version 版本化迁移：同事务失败整体回滚、重启可重试，旧库升级有备份恢复演练（13 工单保留）。
10. **用了哪些开源？合规吗？** 17 个直接依赖：SunnyUI（**GPL-3.0-only**，课设可用、商用需注意传染性）、OpenCvSharp/ZXing.Net/MailKit/Polly/FluentValidation/Quartz.NET/Serilog（Apache-2.0）、QRCoder/ClosedXML/MQTTnet/ScottPlot/BCrypt.Net-Next/FuzzySharp/Bogus/OnnxRuntime（MIT）、QuestPDF（Community）、CsvHelper（MS-PL/Apache-2.0）。许可以官方 NuGet 元数据为准。
11. **怎么保证测试不污染数据？** 冒烟/评测工具强制 --conn 指向独立测试库（业务库名直接拒跑）；SQL 冒烟库中立无 USE 且业务库防护；测试库可随时 DROP 重建。
12. **为什么工程师界面没有"出库"按钮？** 职责分离（RBAC）：`picking.issue` 只授库管员/管理员——出库会扣库存，须由库管确认；界面按权限显隐按钮 + 服务层 Guard 二次校验，绕过界面直接调服务同样被拒（冒烟有越权断言）。
13. **界面主题怎么做的？** 深灰电光蓝单一深色主题：25 个语义色 token（UiKit/Theme.cs），文字对比度按 WCAG 计算并写成 20 项单测守护（正文 ≥4.5:1、图形 ≥3:1）；图表（SunnyUI 深色样式 + ScottPlot）逐项配色，对话框统一 ApplyDialogTheme。
14. **DataGridView 用了哪些最佳实践？**（老师最后课 15 项）显式列 + BindingSource 中介层、DataError 全局兜底、CellValidating+ErrorText 单元格校验、右键复制菜单、双缓冲、隔行着色、分页 + 批量删除单事务（引用检查跳过）等——全部对齐，UiKit.cs 统一工厂产出。
15. **测试规模？** 单元测试 169（含色板对比度 20、全屏状态机 4、EOQ/OEE 算法、迁移脚本嵌入守护 7）；无界面冒烟 85（独立测试库）；Mimosa 深度安全扫描 0 发现。

## 四、可能被追问的实现细节

- 单号规则：WO/PK + yyyyMMdd + 4 位流水，sp_getapplock 串行分配（并发安全）。
- 大屏数据：usp_GetDashboard UNION ALL 四类；CSV 导出 UTF-8 BOM 供外部大屏。
- 照片：一次准备（压缩 800px/JPEG75 + 识别各一次）贯穿预览/提交；失败清空候选、关窗不回写。
- 会话超时：60 秒心跳 Touch()，30 分钟自动登出。
- 迁移机制：01 基线→04 审阅列/约束/索引，逐版本单事务；02 过程/触发器/视图按文件 SHA-256 与库扩展属性比对增量刷新（CREATE OR ALTER，会话显式 QUOTED_IDENTIFIER ON）。
- 权限矩阵（演示用）：admin 12 权限全量；engineer＝接单/审阅/算料（无出库、无派单）；warehouse＝配件/入库/出库/算料（无派单）；reporter＝仅报修与查询。
- 若老师要求跑代码：VS2026 已开着这些标签页——`PartRepository.cs`（BatchDelete 单事务）、`DbInitializer.cs`（版本化迁移）、`UiKit.cs`（网格工厂）、`Theme.cs`（色板）。
