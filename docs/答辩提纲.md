# 答辩提纲（5 分钟陈述 + 预答问）

## 一、开场陈述（约 1 分钟）

- 项目：工业维修智能化零件分配平台——"拍照·识别·算料"一体化智能维修系统。
- 业务闭环：报修拍照 → 自动识别部件 → BOM×冗余智能算料 → 领料出库 → 完工 → 大屏统计。
- 技术栈：C# .NET 8 WinForm + SunnyUI + ADO.NET + SQL Server（存储过程/触发器/视图/事务）+ SerialPort。

## 二、演示脚本（约 3 分钟，按顺序）

1. reporter 登录（验证码）→ 新建报修：选照片 → 右侧实时"拍照识别 Top3"（讲：ZXing 二维码 100% 直达 + OpenCV CLAHE/最大轮廓圆度判形状 ×特征库融合，理由可解释）→ 提交。
2. admin 登录 → 工单中心派单（讲：RBAC，不同角色导航与按钮不同）。
3. engineer 登录 → 接单 → 智能算料：冗余系数 1.10 → 生成明细（讲：BOM×冗余向上取整，任务书"留有一定冗余"）→ 领料出库（讲：存储过程事务，库存不足整体 Rollback）→ 导出Excel（ClosedXML，样式+合计行）。
4. 完工 → 大屏（UIBarChart 状态分布 / UILineChart 近7日 / 工程师排行 / 库存预警，预警由触发器写入）。
5. admin → 配件库「生成二维码」（QRCoder）→ 串口页「从图片扫码」（ZXing 解码闭环，讲：PART:编码 协议统一）。
6. admin → IoT·MQTT遥测：启动网关（讲：MQTTnet 内嵌 Broker 127.0.0.1:18835，无需外部服务；factory/{id}/telemetry 主题）→ 实时温度曲线/健康表 → 越限自动创建 [IoT自动报修] 工单（回工单中心指认）。
7. admin → 用户与日志（登录/操作日志全留痕）。

## 三、亮点回答准备（高频提问）

1. **密码怎么存的？** bcrypt 哈希（cost=11）+ 登录失败 5 次锁 10 分钟 + 图形验证码 + 可选 MFA 邮箱二次验证；SHA-256 用于摘要场景。
2. **防 SQL 注入？** DAL 所有 SQL 用 SqlParameter 参数化；存储过程内部同样参数化，无字符串拼接。
3. **事务在哪里？** 三处：① C# 侧 BeginTransaction（注册用户+日志）；② usp_GeneratePicking 生成领料单（XACT_ABORT+TRY/CATCH ROLLBACK）；③ usp_IssuePicking 出库扣库存（不足即回滚，提示缺口明细）。
4. **触发器做什么？** 工单状态变化自动写流转记录（维修历史）；库存跌破下限自动写预警表；领料明细插入留痕。
5. **识别为什么不用深度学习？** V2 采用"ZXing 二维码直达 + OpenCvSharp 传统视觉（CLAHE/轮廓圆度/主色）×特征库融合"：不依赖训练与 GPU、结果可解释（现场可展示匹配理由）、演示稳定；二维码标签（QRCoder 生成）贴在配件上即达 100% 命中——工业现场比统计模型更可靠。架构上识别引擎独立成类，可平滑替换 CNN/在线 AI 接口。
6. **CSRF 在 C/S 怎么落实？** CSRF 针对 Web 会话；本系统以等价手段落实：会话令牌 + 30 分钟滑动超时 + 操作日志审计。
7. **冗余系数的作用？** 对 BOM 常规用量放大（默认 1.10）并向上取整，保证维修现场耗材损耗有余量，代价是成本统计略高，可在 1.00~2.00 间调整。
8. **怎么部署到别的电脑？** dotnet publish + 目标机 .NET Desktop Runtime 8 + LocalDB，登录页点"一键初始化"自动建库播种。OpenCvSharp 原生库随发布自带上（+约60MB），运行异常自动降级纯托管识别。
9. **MQTT 为什么内嵌 Broker？** MQTTnet 提供 MqttServer，应用内启动免安装 Mosquitto 等外部服务，演示/部署零依赖；真实环境只需把客户端指向厂区 Broker（改连接串即可），代码不变。
10. **用了哪些开源项目？合规吗？** 直接依赖 7 个：SunnyUI、OpenCvSharp、QRCoder、ZXing.Net、ClosedXML、MQTTnet、BCrypt.Net-Next——全部 MIT/Apache-2.0 宽松协议，可闭源使用；详见《GitHub开源参考.md》。

## 四、可能被追问的实现细节

- 单号规则：WO/PK + yyyyMMdd + 当日 4 位流水（存储过程内生成，并发安全）。
- 大屏数据：usp_GetDashboard 一次返回状态分布/近7日/排行/预警四类（UNION ALL）。
- 照片：本地压缩到最长边 800px/JPEG75 再落盘（任务书"本地拍照压缩上传"）。
- 会话超时：主窗体 60 秒心跳 AppSession.Touch()，超 30 分钟自动登出。
