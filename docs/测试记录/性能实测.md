| 场景 | 数据量 | 耗时 | 说明 |
|---|---|---|---|
| 压测数据生成 | 500 张工单（含审阅/领料/出库/完工） | **3.2 秒** | Bogus 逼真描述 + 存储过程全流程（SeedDemoData） |
| 分页查询 | 500 单第 1 页 50 条 | <100ms | OFFSET-FETCH + 条件总数，UiPager 即时响应 |

| 数据库升级 | 旧库（13 工单）→ v2 | <2 秒 | 含 01 基线幂等检查 + 04 审阅列迁移 + 02 过程刷新 |
| 空库初始化 | 建库+16 表+9 过程+播种 4 账号+演示工单 | <5 秒 | 一键初始化（EnsureAll） |
| MQTT 遥测 | 内嵌 Broker 启动+确定性越限帧+自动报修 | <3 秒 | StartAsync(300ms 等待) + PublishTelemetry + 冷却 |

## 数据库写入安全（并发场景）

| 场景 | 结果 |
|---|---|
| 并发生成领料单（同工单） | 恰好一次成功（applock + 唯一过滤索引兜底） |
| 并发出库（同领料单） | 恰好一次成功（UPDLOCK 行锁） |
| 单号分配 | sp_getapplock 串行（WO/PK + 日期 + 4 位流水） |
| 迁移失败 | 整体回滚，版本/哈希不变，重启可重试 |
