# 用户手册（操作指南）

> 面向系统操作者，按角色分节。技术细节请参考 README.md。

## 快速开始

1. 双击桌面「工业维修智能化零件分配平台」
2. 首次使用：点「一键初始化」→ 等待完成
3. 输入账号密码（默认见下表）→ 输入验证码 → 登录

| 角色 | 账号 | 密码 | 权限 |
|---|---|---|---|
| 系统管理员 | admin | 123456 | 全部功能 |
| 库管员 | warehouse | 123456 | 配件/入库/算料/出库 |
| 维修工程师 | engineer | 123456 | 工单/接单/审阅/算料 |
| 报修人 | reporter | 123456 | 报修/查进度 |

## 报修人操作

### 报修
1. 左侧导航「工单中心」→「新建报修」
2. 选择设备 → 选择故障类型 → 选择优先级
3. **快速模板**：选中「轴承异响」等模板自动预填
4. 可选：点「拍照/选择照片」上传现场照片
   - 系统自动识别配件（显示 Top3 候选）
5. 填写描述 → 点「提交报修」

### 查看进度
- 工单列表 → 双击工单或点「详情」
- 查看流转时间线（各阶段耗时一目了然）

## 维修工程师操作

### 接单
1. 管理员派单后，「工单中心」→ 选中 → 「接单」

### 材料审阅（必须步骤）
1. 工单详情 → 材料审阅区
2. **确认重点零件**：点候选旁「确认」按钮，或点「手动选择零件」搜索
3. **或选仅整机BOM**：点「仅按整机BOM配料」→ 填写理由
> 未完成审阅的工单无法生成领料单

### 添加备注
- 工单详情下方备注输入框 → 输入内容 → 回车或点「添加」

### 完工
- 「完工」→ 输入维修总结 → 确认

## 库管员操作

### 入库
1. 「备件库管理」→ 选中配件 → 「入库」
2. 输入数量 → 确认

### 盘点
1. 「备件库管理」→「盘点」
2. 在「实盘数量」列输入清点数 → 差异自动计算
3. 确认调整（正差异入库，负差异调减）

### 领料出库
1. 「智能算料·领料」→ 选中领料单 → 「领料出库」
2. 确认（库存不足会提示缺口）

### 批量操作
- **批量导入**：准备 Excel → 「批量导入」→ 校验 → 确认
- **批量打印标签**：查询配件 → 「批量打印标签」→ 生成 PDF

## 系统管理员操作

### 用户管理
- 「用户与日志」→ 账号管理：启用/禁用/重置密码/调整角色/MFA 开关

### 备份恢复
- 「用户与日志」→ 备份恢复：
  - 「立即备份」→ 可打标签（如"升级前"）
  - 「恢复」→ ⚠ 会覆盖当前全部数据
  - 「删除备份」→ 清理旧备份文件

### 日志审计
- 「登录日志」/「操作日志」页签查看全部记录

## 维护计划中心操作（管理员/工程师）

### 预防性维护调度
1. 左侧导航「维护计划中心」→「预防性维护调度」Tab
2. 点「新增调度」→ 选择设备 → 填写任务名（如"季度轴承润滑"）→ 间隔天数（90=季度）→ 可选填描述
3. 系统每 30 分钟自动检查到期调度，到期即自动创建工单（描述含 `[预防性维护]` 前缀）
4. 可随时点「立即检查」手动触发一次
5. 「已生成工单」列显示每条调度累计自动创建的工单数；工单详情首行会标注 `[来自 PM 调度 #N]`

### 库存优化建议（EOQ）
1. 「维护计划中心」→「库存优化建议」Tab
2. 系统自动计算每个配件的：
   - **EOQ 经济批量**：最优订购数量（平衡订货成本与持有成本）
   - **再订购点**：库存降至该水平时应触发订购
   - **安全库存**：应对需求波动的缓冲量（95% 服务水平）
   - **首选供应商 / 供货价 / 交期**：取配件-供应商关联中的首选（首选优先、其次最便宜）；无关联时交期按默认 14 天
3. 「需订购」列标记为 ✅ 的配件建议立即订购，建议文案含订购渠道与金额估算
4. 下方 ScottPlot 交互图表可缩放/平移查看年消耗量分布；点「导出图表」保存 PNG
5. 点「按建议入库」对全部需订购配件按 EOQ 批量一键入库

### 供应商管理
1. 「维护计划中心」→「供应商管理」Tab
2. 点「新增供应商」→ 填写名称/联系人/电话
3. 选中供应商 → 点「关联配件」→ 输入配件编码 → 设供货价/交期/是否首选（会直接影响 EOQ 建议的交期与渠道）

### 设备停机追踪
1. 「维护计划中心」→「设备停机追踪」Tab
2. 选择设备与停机原因（固定分类下拉：计划维护/故障停机/电气故障/机械故障/操作失误/待料/其他）→ 点「开始停机」
3. 设备恢复后点「结束停机」
4. 列表显示各设备停机次数/总时长/平均时长与 30 天可用率（OEE Availability）
5. 点「导出Excel」可将停机汇总（含可用率）导出为表格

## 常见问题

**Q：登录提示"数据库不存在"？**
A：点「一键初始化」建库。

**Q：照片识别不准？**
A：识别给出的是候选建议，低于 60 分标注"需人工核对"。请在材料审阅中手动确认正确零件。

**Q：出库提示"库存不足"？**
A：先到「备件库管理」→「入库」补充库存。

**Q：如何切换暗色主题？**
A：顶栏右侧「🌙暗色」按钮一键切换，重启自动记住。

**Q：数据误删怎么办？**
A：到「备份恢复」→ 选最近的备份 → 「恢复」。
