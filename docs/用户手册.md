# 用户手册（操作指南）

> 面向系统操作者，按角色分节。技术细节请参考 README.md。

## 快速开始

1. 双击桌面「工业维修智能化零件分配平台」
2. 首次使用：点「一键初始化」→ 等待完成
3. 输入账号密码（默认见下表）→ 输入验证码 → 登录

| 角色 | 账号 | 密码 | 权限 |
|---|---|---|---|
| 系统管理员 | admin | 123456 | 全部功能 |
| 库管员 | warehouse | 123456 | 配件/入库/算料/出库 |
| 维修工程师 | engineer | 123456 | 工单/接单/审阅/算料 |
| 报修人 | reporter | 123456 | 报修/查进度 |

## 报修人操作

### 报修
1. 左侧导航「工单中心」→「新建报修」
2. 选择设备 → 选择故障类型 → 选择优先级
3. **快速模板**：选中「轴承异响」等模板自动预填
4. 可选：点「拍照/选择照片」上传现场照片
   - 系统自动识别配件（显示 Top3 候选）
5. 填写描述 → 点「提交报修」

### 查看进度
- 工单列表 → 双击工单或点「详情」
- 查看流转时间线（各阶段耗时一目了然）

## 维修工程师操作

### 接单
1. 管理员派单后，「工单中心」→ 选中 → 「接单」

### 材料审阅（必须步骤）
1. 工单详情 → 材料审阅区
2. **确认重点零件**：点候选旁「确认」按钮，或点「手动选择零件」搜索
3. **或选仅整机BOM**：点「仅按整机BOM配料」→ 填写理由
> 未完成审阅的工单无法生成领料单

### 添加备注
- 工单详情下方备注输入框 → 输入内容 → 回车或点「添加」

### 完工
- 「完工」→ 输入维修总结 → 确认

## 库管员操作

### 入库
1. 「备件库管理」→ 选中配件 → 「入库」
2. 输入数量 → 确认

### 盘点
1. 「备件库管理」→「盘点」
2. 在「实盘数量」列输入清点数 → 差异自动计算
3. 确认调整（正差异入库，负差异调减）

### 领料出库
1. 「智能算料·领料」→ 选中领料单 → 「领料出库」
2. 确认（库存不足会提示缺口）

### 批量操作
- **批量导入**：准备 Excel → 「批量导入」→ 校验 → 确认
- **批量打印标签**：查询配件 → 「批量打印标签」→ 生成 PDF

## 系统管理员操作

### 用户管理
- 「用户与日志」→ 账号管理：启用/禁用/重置密码/调整角色/MFA 开关

### 备份恢复
- 「用户与日志」→ 备份恢复：
  - 「立即备份」→ 可打标签（如"升级前"）
  - 「恢复」→ ⚠ 会覆盖当前全部数据
  - 「删除备份」→ 清理旧备份文件

### 日志审计
- 「登录日志」/「操作日志」页签查看全部记录

## 常见问题

**Q：登录提示"数据库不存在"？**
A：点「一键初始化」建库。

**Q：照片识别不准？**
A：识别给出的是候选建议，低于 60 分标注"需人工核对"。请在材料审阅中手动确认正确零件。

**Q：出库提示"库存不足"？**
A：先到「备件库管理」→「入库」补充库存。

**Q：如何切换暗色主题？**
A：顶栏右侧「🌙暗色」按钮一键切换，重启自动记住。

**Q：数据误删怎么办？**
A：到「备份恢复」→ 选最近的备份 → 「恢复」。
