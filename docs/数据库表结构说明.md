## 三、表之间的关系

```
sys_role ──< sys_role_permission >── sys_permission
sys_role ──< sys_user ──< sys_login_log

device ──┬──< bom >── part >── part_category
         ├──< work_order（Reporter/Engineer → sys_user；ScheduleId → maintenance_schedule）
         ├──< maintenance_schedule
         └──< downtime_record

work_order ──┬──< work_order_record
             ├─── ConfirmedPartId → part（人工确认重点零件）
             └──< picking_list ──< picking_item >── part

part ──┬──< part_stock_log        （入库/出库流水 → EOQ 消耗分析）
       ├──< stock_alert           （触发器自动预警）
       └──< part_vendor >── vendor（供货价/交期/首选 → EOQ 建议）
算料链路：识别候选(RecognizedJson) → 材料审阅(uspartReviewMaterials) → bom 用量×冗余
         → picking_list/item 快照 → usp_IssuePicking 行锁扣减 part.StockQty
```
